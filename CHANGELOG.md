# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-11-17

### Added
- Initial public release of `grayjay_to_freetube.py`.
- One-click Windows launcher (`Export_Grayjay_to_FreeTube.bat`) with drag-and-drop folder support.
- Linux and macOS shell launcher (`export_grayjay_to_freetube.sh`).
- Automatic Grayjay Desktop folder detection across Windows, macOS, and Linux.
- Support for JSON playlist files, newline-delimited playlist strings, Watch Later exports, and read-only SQLite fallback.
- CLI flags for `--output`, `--no-watch-later`, `--dry-run`, and `--version`.
- Automated unit test suite and GitHub Actions CI workflow.
